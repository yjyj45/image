# 그림책 개요 짜기 (7~8차시)

「데이터 분석 기반 AI 협업 스토리텔링 창작 프로그램」 7~8차시에서 모둠이 그림책 개요를 짜고, 쪽마다 장면 설명과 이미지 생성 프롬프트를 만드는 웹 도구입니다.

- 앱 주소: (GitHub Pages 주소를 여기에 적어요)
- 패들렛(장면 공유판) 리메이크 링크: (여기에 적어요)

## 수업 흐름
1. **모둠 대표(👑):** 6차시 글을 붙여 넣고, 제목·마음·쪽 나누기·담당 번호·주인공 외형을 정해 `개요 전체 복사`를 누릅니다.
2. **모둠원(🤝):** 복사한 개요를 아래 칸에 붙여 넣고 2단계로 갑니다. 내 번호를 고르면 내 쪽만 보입니다.
3. **각자:** 장면과 프롬프트를 쓰고, 3단계에서 복사해 캔바에서 이미지를 2~3개 만든 뒤 가장 어울리는 하나를 패들렛에 올립니다.

## 개인정보와 보관
- 서버가 없습니다. 쓴 내용은 학생 기기의 브라우저(localStorage)에만 저장되고, 외부로 보내지 않습니다.
- 학생 이름·학번은 쓰지 않도록 안내해 주세요. 모둠 이름(번호)만 씁니다.
- 공용 기기에서는 수업 뒤 브라우저의 사이트 데이터 삭제를 권합니다.
- 외부 글꼴이나 외부 스크립트를 쓰지 않습니다.

## 선택 기능: 시트로 보내기
교사가 구글 Apps Script를 직접 배포했을 때만 쓰는 기능입니다. 제출 코드를 붙여 넣기 전에는 버튼이 보이지 않습니다. 설정은 `Apps스크립트_설정안내.md`, 코드는 `Code.gs`를 보세요. 쓰지 않으면 학생은 `파일로 저장`으로 냅니다.

## 알아 둘 점
- 패들렛은 6모둠 · 모둠 안 번호 1~5 · 표지~6쪽에 맞춰 만들었습니다.
- 학교 기기에서 브라우저 저장이 지워질 수 있으니, 중요한 내용은 `파일로 저장`으로 남기게 하세요.
